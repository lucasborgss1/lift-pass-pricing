# Lift Pass Pricing Java API

Lift Pass Pricing Refactoring Kata.

This is a Java [Maven](https://maven.apache.org/) project.

To install dependencies:

    mvn verify

The project uses [JUnit 5](https://junit.org/junit5/) and [REST assured](http://rest-assured.io/) for testing.

To run the tests:

    mvn test

To start the application:

    mvn exec:java

## Créditos

Este projeto parte do [Lift Pass Pricing Refactoring Kata](https://github.com/martinsson/Refactoring-Kata-Lift-Pass-Pricing),
criado por Johan Martinsson. A versão em Java foi portada por Peter Kofler.
O conteúdo da pasta `java/` do kata foi trazido para a raiz deste repositório, junto com
o script `database/initDatabase.sql`.

Código original usado para fins acadêmicos; este repositório contém modificações.
